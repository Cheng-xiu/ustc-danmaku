# 科大弹幕录：绩点保卫战

计算机程序设计 C* 课程项目。计划使用 C99 或 C11 与 EasyX，在 Windows 上实现弹幕游戏及离线 AI 训练器。

## 项目规范

**完整 PDF 是项目理解和实现的依据：** [最终项目规划与交付规范 v3.1](docs/project-spec-v3.1.pdf)。

PDF 原文件：`科大弹幕录_最终交付文档_v3.1.pdf`（2026-10-05，共 23 页）。本仓库保存其原始字节，不以精简版本替代。

后续工作先阅读完整规范；文档未规定或不清楚的关键问题向项目用户确认。用户后续明确的修改要求优先于原规范，并应记录变化。

## 当前状态

仓库仅完成文档初始化，尚未包含游戏、训练器或模型实现。

规划中的游戏与训练器共用纯 C 逻辑核心；遗传算法优化玩家陪练策略，Boss 使用情境老虎机学习选招，正式游戏读取同一训练链的冻结快照。具体玩法、计分、训练与交付要求均见完整 PDF。
