# 科大弹幕录：网页最小可玩 Demo

需要 Node.js 22.12+。解压后双击 `Start-Web-Demo.bat`，在本地浏览器开始试玩。
无需编译器、Emscripten 或 npm 安装。请保留服务窗口，结束时 Ctrl+C。

鼠标移动，WASD/方向键备用；1–4 出招；Esc/右键暂停；R 重开。
默认配置 v2、种子 20261006、3 名脚本学生，无训练模型。
