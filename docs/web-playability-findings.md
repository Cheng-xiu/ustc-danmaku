# 无尽 Demo 游戏性评估

当前cfg5四招由实际几何、费用、速度和占用时间形成用途差异：快速周边双环、分列弹墙、单目标窄扇三连、满能量持续扫描雨。顶部能量与共享CD明显显示，开局给出技能说明，玩家可把注意力留在战场。详细前后对照与留出结果见[v5平衡报告](web-balance-findings-v5.md)。

## 已得到的证据

12种子、3/8人、静止/贴近/常规追击/绕行和单招/混招/不出招的1,152局主要前后对照已完成；另有三种场地216局检查。首次留出常规追击的三人开局四招均能清波；八人中金矿对多人清场较慢，墙和雨更适合广域压制，环以较短占用换取位置要求。初选弹墙过强，已减为两波并调高至50能量。

实际单文件浏览器也完成了合法键盘清第一波、完整2秒固定预告与4人出生；清波没有胜利界面，GPA真实增长，重开清零。它支持当前操作、选招和人数递增循环能运行，不替代真人对乐趣和难度的判断。

## 后续建议

1. 先找5–10名首次玩家，记录是否能区分四招、误判CD的次数、首死时间和重开意愿；这比继续增加弹量更能检验本轮改动。
2. 增加命中/击倒的即时反馈，再看玩家是否理解何时换招。金矿因其他学生靠近原点会拒绝，可将拒绝原因显示得更具体；仍保持拒绝不扣能量，不隐藏重抽。
3. 课表全周期5秒恰好回50能量，长期资源选择仍有限；若后续调整攻击期间回能或引入新的冷却规则，先确认范围再单独对照。
4. 竖场中顶部弹墙在4秒内未覆盖最底部，环的相对优势也会增加。后续训练和真人试玩应覆盖横屏/竖屏，不能把默认场地的排名推广到所有比例。
5. 八人上限后当前脚本与数量不再增强。未来引入更强训练学生时公开标明阶段，并以实测表现判断难度，训练迭代次数本身不能证明更难。

上述建议未新增为游戏规则。游戏尚未训练机器学习学生；自动实验不能证明完全平衡、长期体验或所有设备性能。[v4历史评估](archive/web-playability-findings-v4-20261007.md)保留当时的玩法与回放记录。
