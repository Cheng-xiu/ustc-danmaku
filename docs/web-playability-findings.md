# 无尽 Demo 游戏性评估 v6

本版增加按住预瞄、松开释放和空格取消，四招沿鼠标方向出弹。新一次按住从当前 Boss 指向鼠标；持有后角色移动不自动改变角度，真正移动鼠标才调整。这样减少接近指针时的反转，也让玩家在扣能量前看到方向与首波路线。完整规则、检查证据和建议见 [瞄准报告](validation/aim-v6.md)。

四招的主要区别是前向宽弧、分列封路、窄扇三连和扫描雨，费用仍为25/50/20/100。墙和雨从场地边缘入场，环和矿从角色出生；预瞄明确显示这些差别。持有不会暂停敌人或免费占用 CD，取消不扣费，也不会清除 WASD 移动。

三窗口的实际自动浏览器输入验证预瞄、接受和首发一致，包括边界、移动中瞄准、按钮拖出、暂停和重开。原生测试另验证能量事务、所有波次、拒绝、GPA和无尽裁决。当前仍是脚本学生，未训练机器学习；自动控制能够运行不等于真人觉得好玩或四招完全平衡。v5 的2808局数值实验针对旧自动方向形状，保存在 [历史平衡报告](web-balance-findings-v5.md)，不能直接作为 v6 排名。

后续建议按优先级：

1. 找首次玩家测试按住、松手、取消是否容易学会，记录误发次数和同时移动瞄准的负担。可比较“瞄准时轻微减速”是否更舒适；本版未改变移动速度。
2. 金矿120距离拒绝可进一步显示接近的学生，让玩家理解拒绝原因。现行规则与拒绝不扣费保持一致。
3. 方向线是近似弹道，攻击结束会清除本招弹；可让 C 额外提供每波真实可达范围，减少长条预瞄的误读。本版没有在 TS 估算伤害范围。
4. 补足命中、击倒与松手成功的即时视觉/音效反馈，并在真人试玩后决定是否必要。
5. 针对手动方向重新做独立种子、多窗口和不同瞄准能力的平衡实验；未来机器学习沿用同一 C 手动方向接口，不能继续拿 legacy 自动目标结果当产品行为。

这些是待测试建议，没有额外加入玩法。长期难度、弱设备性能和真人体验仍需后续实测。
