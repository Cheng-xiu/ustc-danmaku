## 试玩顺序

1. 读菜单后开始一局，记录理解“我是Boss、通过击倒持续加分”的时间。
2. 尝试鼠标、WASD、数字键/按钮、暂停与重开；记录预警和反击弹是否清楚。
3. 分别试环弹、课表、金矿、满能量第四招，再试混招。记录换招/等待的理由和矿点拒绝的场景。
4. 用常规距离、近身和绕行比较失血与击倒；注意清波后2秒出生预告。
5. 每局先玩2–5分钟，记录人数增加是否带来新选择、八人后是否单调，以及是否愿意重开。
