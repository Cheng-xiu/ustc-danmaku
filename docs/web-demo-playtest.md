## 试玩顺序

1. 读开局技能介绍后开始一局，记录理解“我是Boss、通过击倒持续加分”和四招区别的时间。
2. 尝试鼠标、WASD、数字键/顶部按钮、暂停与重开；鼠标移入顶栏或离开Canvas时仍应跟随，键盘仍能操作。切到另一窗口应自动暂停；记录预警、学生反击、能量和共享CD是否清楚。
3. 分别试25能量快速双环、50能量分列墙、20能量窄扇三连、100能量全场雨，再试混招。记录换招/等待理由、矿点拒绝与共享CD是否被误认为四套独立冷却。
4. 用常规距离、近身和绕行比较失血与击倒；注意清波后2秒出生预告。
5. 每局先玩2–5分钟，记录人数增加是否带来新选择、八人后是否单调，以及是否愿意重开。
6. 改变窗口宽高比例或进入/退出浏览器全屏：本局等比缩放、可留边，圆形校徽和已公开预警保持；重开后应按新比例铺满。分别记下旧/新窗口、实际战场尺寸和异常。
