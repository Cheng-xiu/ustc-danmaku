# 网页最小版真人试玩记录

状态：待收集真人反馈。工程测试与脚本回放不填写为真人记录。

先按 [运行指南](web-demo-guide.md) 打开游戏。默认配置 v2、种子 20261006、3 名脚本学生；每次重开相同种子，便于比较。

## 建议试玩顺序

1. 看菜单后开始一局，记录多久理解“自己是 Boss、要击倒全部学生”。
2. 尝试移动、四个按钮或数字键、暂停、重开；记录预警与实际危险是否看得清。
3. 常规距离玩一局，再试近身追击；记录反击压力和走位是否有意义。
4. 比较单一招式与混招，记录什么时候想等待蓄能、什么时候想换招，以及矿点拒绝能否理解。

每局可先玩 2–5 分钟；游戏不设时限，主动退出记“未完成”。无需先玩出胜局。

## 汇总后作决定

优先核对能量恢复是否需要降低、近身 60 px 反击空档是否过大、矿点拒绝是否易懂、四招是否都有用途。记录拟修改项、原因及对照方法；批准后递增配置版本、重跑受影响的工程检查并重新试玩。后续机器学习辅助平衡另按 [AI 平衡规划](ai-balance-plan.md) 开展。
