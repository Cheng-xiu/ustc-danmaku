顶部为能量、共享CD、血量、分数与操作栏，余下窗口为战场；四招介绍在开始菜单。每局按窗口战场比例采用等面积场地，用户确认中途改变比例时本局等比缩放、重开再铺满。鼠标进入HUD仍能移动，缓存屏幕坐标每tick按当前变换投影，键盘移动优先。提示固定行高，避免改变战场比例；非法尺寸重开保留旧局并显示提示。
